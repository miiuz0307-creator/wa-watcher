# 👁️ WA Watcher — צופה הודעות וואטסאפ

ממשק שמתחבר לוואטסאפ שלך כ**מכשיר מקושר** (QR), שומר כל הודעה שנכנסת אליך —
כולל **הודעות קוליות** — ומראה לך גם הודעות ש**השולח מחק**, עם הטקסט/המדיה המקוריים.

> ⚠️ **חשוב:** זה עובד רק על הודעות שנשלחות **למספר שאתה מחבר** (אתה צד בשיחה).
> אין כאן כניסה למכשיר של אף אחד אחר. חיבור לא-רשמי כזה נוגד את תנאי השימוש של
> WhatsApp ועלול לגרום לחסימת מספר — מומלץ להשתמש ב**מספר ייעודי**, לא העסקי הראשי.

---

## דרישות
- Node.js 18 ומעלה
- טלפון עם וואטסאפ פעיל

## התקנה והרצה

```bash
cd wa-watcher
npm install
npm start
```

יפתח שרת בכתובת: **http://localhost:3000**

1. פתח את הכתובת בדפדפן.
2. יופיע קוד QR.
3. בטלפון: וואטסאפ › **הגדרות** › **מכשירים מקושרים** › **קישור מכשיר** → סרוק.
4. מרגע החיבור — כל הודעה נכנסת תופיע בממשק בזמן אמת.
5. לשונית **"נמחקו"** מרכזת את כל ההודעות שהשולח מחק, עם מה שהיה כתוב בהן.

---

## איך זה עובד
- **Baileys** מתחבר כמכשיר מקושר (אותה טכנולוגיה כמו וואטסאפ web).
- כל הודעה נכנסת נשמרת **מיד** ל-SQLite (`messages.db`), ומדיה מורדת לתיקיית `media/`.
- כשהשולח מוחק הודעה "לכולם", וואטסאפ שולח אירוע מחיקה — אנחנו כבר מחזיקים את המקור,
  מסמנים אותו כ"נמחק" ומראים לך אותו.

## קבצים
| קובץ | תפקיד |
|------|-------|
| `server.js` | השרת — חיבור וואטסאפ, שמירה, זיהוי מחיקות, Socket.IO |
| `db.js` | שכבת SQLite |
| `public/index.html` | הממשק (RTL, QR, הזנה חיה, לשונית נמחקו) |
| `auth/` | נוצר אוטומטית — פרטי ההתחברות (אל תמחק אם לא רוצה לסרוק שוב) |
| `media/` | קבצי מדיה שהורדו |
| `messages.db` | מסד הנתונים |

## הערצה על שרת (Railway / VPS)
- ודא ש-`PORT` נקרא ממשתנה סביבה (כבר מוגדר בקוד).
- שמור על התיקיות `auth/` ו-`media/` עם אחסון קבוע (volume), אחרת תצטרך לסרוק מחדש.
